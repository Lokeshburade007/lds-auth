# @securepool/application

Application / business-logic layer of the [SecurePool](https://github.com/Lokeshburade007/lds-auth) authentication library — `AuthService`, `RefreshTokenService`, and the repository / hasher / token-service / OTP / email interfaces that infrastructure & persistence implement.

You usually don't install this directly. Install [`@securepool/api`](https://www.npmjs.com/package/@securepool/api) for a complete drop-in Express server.

```bash
npm install @securepool/application
```
