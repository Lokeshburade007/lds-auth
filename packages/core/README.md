# @securepool/core

Domain entities and enums for the [SecurePool](https://github.com/Lokeshburade007/lds-auth) authentication library — `User`, `Role`, `Session`, `OtpCode`, `RefreshToken`, `AuditLog`, etc. Zero dependencies.

This package only exports types and value objects. You usually don't install it directly — install [`@securepool/api`](https://www.npmjs.com/package/@securepool/api) (backend) or [`@securepool/react-sdk`](https://www.npmjs.com/package/@securepool/react-sdk) (frontend) instead.

```bash
npm install @securepool/core
```
