# @securepool/infrastructure

Infrastructure adapters for the [SecurePool](https://github.com/Lokeshburade007/lds-auth) authentication library:

- bcrypt password hasher
- RS256 JWT token service
- OTP service (numeric codes with expiry & attempt limits)
- Nodemailer-based email service
- Google ID-token verification

You usually consume these through [`@securepool/api`](https://www.npmjs.com/package/@securepool/api).

```bash
npm install @securepool/infrastructure
```
